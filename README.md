# Magnetide — release downloads

This public repository contains downloadable release builds only. The game's source code remains in a separate private repository.

## Latest release

Download the files from the [latest release](https://github.com/i-n-sinitsin/magnetide-releases/releases/latest).

| Platform | File | Notes |
| --- | --- | --- |
| Windows 64-bit | `Magnetide-0.1.2-windows-x64.exe` | Portable desktop build |
| Linux 64-bit | `Magnetide-0.1.2-linux-amd64.deb` | Debian/Ubuntu package; apt installs dependencies |
| Linux 64-bit | `Magnetide-0.1.2-linux-x64.tar.gz` | Portable archive |
| Android | `Magnetide-0.1.2-android-debug.apk` | Debug build for testing/sideloading; not a Google Play release |

Install the Linux package with:

```bash
sudo apt install ./Magnetide-0.1.2-linux-amd64.deb
```

SHA-256 checksums for all files are attached to the release as `SHA256SUMS.txt`.

The browser version is available at [magnetide-prerelease.pages.dev](https://magnetide-prerelease.pages.dev/), and the itch.io page is [i-n-sinitsin.itch.io/magnetide](https://i-n-sinitsin.itch.io/magnetide).
