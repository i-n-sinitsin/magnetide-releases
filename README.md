# Magnetide — release downloads

This public repository contains downloadable release builds only. The game's source code remains in a separate private repository.

## Magnetide 0.1.0 for Linux (64-bit)

Download `Magnetide-0.1.0-linux-amd64.deb` from the [v0.1.0 release](https://github.com/i-n-sinitsin/magnetide-releases/releases/tag/v0.1.0).

Install on Debian, Ubuntu, Linux Mint, or another compatible distribution:

```bash
sudo apt install ./Magnetide-0.1.0-linux-amd64.deb
```

Package architecture: `amd64`. Required system packages are installed by apt.

The browser version is available at [magnetide-prerelease.pages.dev](https://magnetide-prerelease.pages.dev/), and the itch.io page is [i-n-sinitsin.itch.io/magnetide](https://i-n-sinitsin.itch.io/magnetide).
